## Plan: Web AGC/DSKY – Accessible Lunar Landing Simulation (PC Only)

Develop a desktop-focused, accessible AGC/DSKY lunar landing simulation with keyboard and mouse support.

Prioritize accuracy in code translation to maintain authentic AGC behavior.

### Steps
1. Design a wide (1500+ px) HTML/CSS layout: DSKY controls (left), schematic lunar module landing view (right).
2. Implement DSKY UI in JavaScript/HTML: support keyboard navigation (tab, arrow keys, enter) and mouse input for commands 63–68.
3. Simulate AGC landing logic: model only the landing sequence, reflecting DSKY inputs/outputs.  
4. Create a basic schematic lunar module landing visualization: simple shapes for module, burners, and moon surface, updating per simulation state.
5. Add a timer slider (1x–20x): accessible via keyboard and mouse, controlling simulation speed.
6. Integrate all components: ensure DSKY actions drive the landing simulation and visualization.
